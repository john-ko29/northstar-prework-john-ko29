## WHat is this

A project to use Python and Excel to create a Weekly Sales Report

## What's in the repo

hello_northstar.py - a python script to create a weekly sales summary report and export the results to a txt file.

region_summary_report.txt - a txt file exported from a Python script

hello_northstar_analysis.xlsx - Excel file that shows a summary of the weekly sales with sorting and filtering options

## What did I find

I found the total sales, average sales, highest sale and the lowest sale. The regions with sales above average are the North and East regions. THe regions with sales below average are the South, West and the Central regions.

## AI Use Note

I used AI. I used it for the max() and min() functions so that I get the key matched with the highest or lowest sale. I verified by running the script and seeing if the results match as well changing the numbers to see if it changed.
